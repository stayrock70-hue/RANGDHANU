# Rangdhanu (রংধনু)

A colourful fashion storefront: Women, Men, Kids, Shoes & Bags, New In and Sale,
with size selection, filters, wishlist, bag, search and company pages.

## Files

- `index.html` — the whole site (HTML, CSS and JavaScript)
- `photos.js` — list of product photos by category
- `images/` — product photos (StockSnap.io, CC0 licence)

## Hosting

Upload `index.html`, `photos.js` and the `images/` folder to your web host's
public folder (on Hostinger: `public_html`). No build step or server code is needed.
